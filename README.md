# Ландшафтный дизайн участка с автоматизацией через Claude

Документ фиксирует результаты подбора программного обеспечения для проектирования загородного участка с
возможностью подключить Claude через MCP или API. Исходные данные: топографический план в формате DWG с
нанесёнными зданиями, деревьями, отметками высот и горизонталями.

## Требования

- Импорт топографического плана DWG с сохранением слоёв, построение рельефа по горизонталям и отметкам.
- Простота освоения для пользователя без опыта работы в CAD.
- Фотореалистичная 3D-визуализация с режимом прогулки по участку.
- Геопривязка участка по координатам, расчёт положения Солнца по дате и времени суток для проектирования
  освещения и анализа теней от дома и деревьев.
- Библиотека растений с реальными видами, возможность задать возраст дерева и увидеть, как изменится
  визуализация при его росте.
- Библиотеки материалов для дома, дорожек, построек, заборов, прудов и ручьёв.
- Подключение Claude через MCP или API для автоматизации.

## Рассмотренные варианты

### SketchUp Pro + Twinmotion

SketchUp Pro импортирует DWG, строит рельеф по горизонталям инструментом Sandbox From Contours, имеет
геопривязку по координатам и панель Shadows с расчётом теней по дате и времени. Twinmotion обеспечивает
фотореалистичную прогулку, библиотеку материалов и растений, ползунок возраста деревьев. API SketchUp на Ruby,
есть официальный коннектор Trimble для Claude и сообщественные MCP-серверы.

### Rhino + Lands Design + Twinmotion

Rhino читает DWG без потерь. Lands Design добавляет базу из 8200 видов растений с ботаническими названиями,
возраст растений в годах с расчётом размера по темпу роста вида, инструменты рельефа с подсчётом земляных
работ, параметрические дорожки, стены, заборы и ведомости. Визуализация через Twinmotion по экспорту
Datasmith. API Rhino на Python (RhinoCommon), Grasshopper, headless-режим Rhino.Compute, сообщественные MCP.

### Realtime Landscaping Architect

Наиболее простая программа, созданная под задачу: импорт DWG, рост растений от 3 месяцев до 20 лет, библиотека
около 17 тысяч растений с сортами, пруды, ручьи и фонтаны как готовые объекты, солнце по координатам и дате.
Не имеет API, формат файлов закрытый, качество графики ниже Twinmotion. Отклонена из-за отсутствия
возможности подключить Claude.

### Отклонённые варианты

- Специализированные бытовые программы (Punch!, Garden Planner): нет API.
- Lands Design для AutoCAD: AutoCAD сложнее Rhino при тех же возможностях плагина.
- Blender, FreeCAD: развитые MCP, но высокий порог входа для пользователя без опыта.
- Собственное веб-приложение (ezdxf + браузерный редактор + свой MCP): полный контроль, но объём разработки
  оправдан только при потоке проектов.

## Сравнение двух основных связок

| Требование | SketchUp Pro + Twinmotion | Rhino + Lands Design + Twinmotion |
|---|---|---|
| Простота освоения | Высокая | Средняя, одна-две недели привыкания |
| Импорт DWG | Есть, слои сохраняются | Родной формат, без потерь |
| Рельеф из горизонталей | Sandbox From Contours, ручная доводка | Terrain, выемка и насыпь, подпорные стенки, объёмы |
| Прогулка, фотореализм | Twinmotion | Twinmotion, дополнительно рендер в Rhino |
| Геопривязка | Add Location, спутниковая подложка | EarthAnchorPoint, спутник и рельеф с карт |
| Солнце по дате и времени | Shadows в SketchUp, Twinmotion | Sun в Rhino, Twinmotion |
| Искусственное освещение | Twinmotion, включая IES | Twinmotion, включая IES |
| Библиотека растений | Только Twinmotion, сотни видов | 8200 видов с карточками, плюс Twinmotion |
| Сорта | Нет | В карточке базы, 3D-модель одна на вид |
| Возраст дерева | Ползунок без привязки к годам | В годах, по темпу роста вида |
| Сезоны | Twinmotion | Lands Design и Twinmotion |
| Материалы | Twinmotion, 3D Warehouse | Twinmotion, материалы Rhino |
| Пруды, ручьи | Геометрия вручную, вода в Twinmotion | Ландшафтные объекты, вода в Twinmotion |
| Дорожки, заборы, стены | Вручную | Параметрические объекты |
| Ведомости растений и площадей | Плагинами | Штатно, экспорт в Excel |
| API | Ruby | Python, Grasshopper, Rhino.Compute |
| MCP | Официальный коннектор Trimble, сообщественные серверы | Сообщественные серверы для Rhino и Grasshopper |
| Стоимость | SketchUp Pro около 350 $ в год | Rhino около 1000 $ и Lands Design около 800 € бессрочно |
| Покупка из РФ | Через реселлера | Через реселлера |

Ни одна из программ не имеет отдельных 3D-моделей для сортов: сорт хранится в карточке базы данных,
модель одна на вид.

## Работа с файлами DWG

Rhino читает DWG родными средствами и сохраняет почти все элементы чертежа. SketchUp при импорте
отбрасывает текст, штриховки, размеры, точки и атрибуты блоков.

| Элемент DWG | SketchUp Pro | Rhino |
|---|---|---|
| Слои | Становятся тегами | Слои с цветами и видимостью |
| Горизонтали (полилинии, сплайны, 3D-полилинии) | Ломаные из отрезков, сплайны разбиваются | Кривые сохраняются, отметка Z сохраняется |
| Отметки высот как текст | Не импортируются | Импортируются как текст, доступны скрипту |
| Блоки (деревья, знаки, колодцы) | Компоненты без атрибутов | Экземпляры блоков с атрибутами |
| Штриховки | Не импортируются | Импортируются |
| Размеры, выноски | Не импортируются | Импортируются |
| Точки (POINT) | Не импортируются | Точки |
| Обратный экспорт в DWG | Есть, геометрия огрублённая | Полноценный, со слоями и блоками |

Особенности топографической съёмки:

- Отметки высот обычно стоят текстом рядом с точкой или как блок с атрибутом. SketchUp их не импортирует,
  остаются только горизонтали. Rhino читает текст, из него скриптом собирается облако точек с высотами.
- Координаты в местной системе (МСК) находятся в миллионах метров от начала координат. SketchUp на таких
  расстояниях теряет точность, файл требуется сдвигать к нулю заранее в AutoCAD. Rhino работает в двойной
  точности, но перенос к началу координат также рекомендуется; выполняется одной командой с сохранением
  смещения.
- Если съёмка выполнена в Civil 3D, горизонтали и поверхности могут быть объектами Civil, которые ни Rhino,
  ни SketchUp не читают. В этом случае у геодезиста следует запросить файл, сохранённый через «Экспорт в
  AutoCAD», либо DXF версии 2010-2013.

Rhino позволяет вернуть архитектору или геодезисту DWG с дорожками и посадками в тех же слоях для
продолжения работы в AutoCAD. Из SketchUp такой обмен получается односторонним.

## Профили пользователей продуктов

### SketchUp

Самый массовый 3D-инструмент среди проектировщиков без инженерной подготовки: архитекторы на стадии
эскиза, дизайнеры интерьеров, частные ландшафтники и садовые студии, мебельщики, строители малоэтажных
домов, а также владельцы участков, проектирующие для себя. Типичная задача: быстро показать объём и
картинку; точность и рабочая документация вторичны.

### Rhino

Среда для точной геометрии и сложных форм. Основная аудитория: промышленный дизайн, ювелирное дело,
яхтостроение, архитектурные бюро с параметрическим проектированием (Grasshopper), фасадные и конструкторские
компании, цифровое производство. В ландшафтном проектировании Rhino применяется главным образом ради
Lands Design и Grasshopper.

### Lands Design

Нишевый продукт компании Asuni. Пользователи: ландшафтные архитекторы и бюро, работающие в Rhino или
AutoCAD и применяющие BIM-подход (база растений, ведомости, рельеф с земляными работами, IFC для передачи
в Revit), а также садовые дизайнеры, которым требуется автоматизация планов посадок. Распространён в Европе
и Латинской Америке, в России малоизвестен.

### Twinmotion

Визуализация для проектировщиков без отдельного специалиста по рендеру: архитекторы, ландшафтники,
застройщики, агентства недвижимости. Аудитория выросла после введения бесплатной лицензии для учёбы и
некоммерческого использования. Модель приходит из SketchUp, Rhino, Revit или ArchiCAD; конкуренты в той же
нише Enscape и Lumion.

### Realtime Landscaping Architect

Небольшие ландшафтные и бассейновые подрядные фирмы в США, которые показывают клиенту будущий вид двора
и сразу составляют смету. Инструмент продаж, а не проектирования; проектные бюро им не пользуются.

Для рассматриваемой задачи пользователь по навыкам ближе к аудитории SketchUp, по требованиям к аудитории
Lands Design. Связка Rhino и Lands Design осваивается на уровне 2D-плана и рельефа без глубины, которую
требует промышленный дизайн.

## Устройство связки Rhino и Lands Design

Lands Design является плагином и отдельно от Rhino не запускается. После установки в окне Rhino появляется
дополнительная вкладка панели инструментов и боковая панель Lands; работа ведётся в одном интерфейсе.

- Стандартные инструменты Rhino сохраняются: кривые, слои, размеры, импорт DWG. Lands Design добавляет
  объекты: рельеф, дерево, живая изгородь, газон, дорожка, стена, лестница, забор, ведомости. Объекты хранятся
  в том же файле 3dm рядом с обычной геометрией.
- Объекты Lands Design параметрические: дерево хранит вид и возраст, дорожка ширину и материал, рельеф
  исходные горизонтали. Свойства редактируются в карточке объекта. Любой объект можно разбить в обычную
  геометрию Rhino для ручной доработки.
- Типичный порядок: импорт DWG средствами Rhino, построение рельефа командой Terrain из выделенных
  горизонталей, размещение растений из базы кликом на плане (растение встаёт на поверхность рельефа),
  преобразование нарисованной кривой в дорожку заданной ширины, формирование ведомости растений.
- Переключение между 2D-планом с условными знаками для печати и 3D-моделью для визуализации выполняется
  внутри одного файла.

Lands Design выпускается также как плагин к AutoCAD с теми же функциями. Существует вариант RhinoLands:
Rhino с уже встроенным Lands Design, продаётся одной лицензией.

## Связь с Twinmotion

Twinmotion является отдельной программой, в которой модель не рисуется, а оснащается материалами, светом и
растительностью и показывается. Связь с Rhino и SketchUp обеспечивает бесплатный экспортёр Datasmith от
Epic Games.

- Экспортёр добавляет в Rhino кнопку Datasmith с двумя режимами: сохранение файла .udatasmith и
  Direct Link. В режиме Direct Link обе программы открыты одновременно; после команды Synchronize в Rhino
  модель обновляется в Twinmotion. Файл 3dm остаётся единственным источником геометрии.
- Переносятся геометрия, слои, материалы по именам, блоки как экземпляры. Объекты Lands Design приходят как
  геометрия с именем вида, без параметров.
- Первичная настройка в Twinmotion: назначение материалов библиотеки поверх материалов Rhino, установка
  места и даты для Солнца, добавление светильников, замена деревьев Lands Design на растения Twinmotion
  (выделяются все объекты одного вида и заменяются из библиотеки с сохранением позиций).
- При повторной синхронизации назначенные материалы, замены и свет сохраняются. Правки геометрии
  выполняются в Rhino, настройка визуализации не повторяется.
- Только в Twinmotion выполняются: покраска газона и травы кистью по рельефу, рассыпание подлеска и цветов,
  расстановка людей и техники, время суток, сезон, погода.
- Прогулка: камера с управлением клавиатурой и мышью на высоте глаз, режим VR.
- Результат: изображения, видео по маршруту, панорамы 360, Twinmotion Cloud (ссылка для просмотра в
  браузере без установки), автономный файл презентации.

Требования к оборудованию: дискретная видеокарта уровня RTX 3060 и выше, оперативная память от 16 ГБ.
На встроенной графике Twinmotion не работает.

## Автоматизация через Claude

Связка на Rhino подходит для работы с агентом заметно лучше:

- Скрипты на Python 3 с документированным API RhinoCommon, в отличие от Ruby в SketchUp.
- Библиотека rhino3dm читает и записывает файлы 3dm без запуска программы.
- Rhino.Compute запускает Rhino как сервер без интерфейса, что даёт полностью автоматический конвейер.
- Grasshopper обеспечивает параметрические сценарии: дорожки по кривым, посадки с заданным шагом и отступами.
- Растения Lands Design хранят вид, возраст и высоту в атрибутах объекта, доступных из кода.
- Геометрические расчёты (тени, площади, объёмы) выполняются точно, а не по снимкам экрана.

Ограничения:

- У Lands Design нет открытого документированного API, его объекты создаются вызовом команд из скрипта.
  Глубину доступа к базе растений следует проверить на пробной версии.
- Twinmotion не имеет API: свет, материалы и финальная визуализация настраиваются вручную.
- Сообщественные MCP-серверы могут ломаться при обновлениях программ. Рекомендуется использовать MCP как
  мост для выполнения скриптов в открытой модели, а логику держать в скриптах в репозитории.

Предполагаемый порядок работы: Claude в Rhino строит рельеф из DWG, размещает существующие здания и деревья,
раскладывает дорожки и посадки по заданным правилам, считает инсоляцию по зонам и ведомость растений;
пользователь правит результат вручную и экспортирует модель в Twinmotion для визуализации.

## Рекомендация

Rhino + Lands Design + Twinmotion. По визуализации, солнцу, материалам и освещению связки равны, разница в базе
растений, возрасте в годах, ландшафтных инструментах и глубине автоматизации, где Lands Design впереди.
Цена решения: освоение Rhino и примерно вдвое большая стартовая стоимость при бессрочной лицензии.

SketchUp Pro + Twinmotion остаётся вариантом, если приоритет отдаётся началу работы в первый день.
